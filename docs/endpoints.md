# Endpoints da API

## Categorias

Base URL:
 /api/v1/categorias

GET    /api/v1/categorias
GET    /api/v1/categorias/{id}
POST   /api/v1/categorias
PUT    /api/v1/categorias/{id}
DELETE /api/v1/categorias/{id}
